# Homework

What a sprint left behind, written down at the moment it closed so nothing depends on memory.

A sprint closes when its goal is met, not when every task is finished. Anything unfinished, blocked on the client,
or discovered late lands here with an owner and a next action, and it is the first thing read at the next
sprint's planning.

## Files

| File | Covers |
|---|---|
| [`sprint-1.md`](sprint-1.md) | Left over from Sprint 1 (closed 9 Oct 2026) |

Add one file per sprint, named `sprint-<n>.md`. When an item is done, delete it from the file rather than
marking it complete — the file is a live list, and git remembers the rest.

Each item says: **what is left**, **why it matters**, **the next concrete action**, and **where it is tracked**.
Group by owner. Keep it short enough to read at the start of planning.
